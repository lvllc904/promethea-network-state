# Conversational Pivot Protocol (CPP)
## Directed Semantic Graphs & Mind Map Canvas Specification

### Abstract
Traditional chat interfaces suffer from Synchronous Lock-In. The **Conversational Pivot Protocol (CPP)** transitions conversational AI from linear chat histories to a **Directed Semantic Graph (DSG)**.

### Core Capabilities
1. **Asynchronous Interruption:** Hot-halting running streams without losing partial generation context.
2. **Dynamic Splicing:** Branching parallel thought paths from any past historical node.
3. **Spatial Mind Map Canvas:** Interactive visual representation of non-linear human-AI diplomatic co-reasoning.
4. **Open SDK:** Distributed as `@promethea/cpp-client` and `@promethea/cpp-server`.
